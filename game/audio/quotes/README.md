# Replaceable real voice clips

Add real, rights-cleared recordings as `milei_quote_01.ogg` through `milei_quote_10.ogg` (MP3 is also accepted). Keep each clip short, normalized, and trimmed cleanly. These files load only when an audio-enabled run starts. See `docs/diaper-run/audio-clip-candidates.md` for researched source pointers and transcript timestamps.

No synthesized or cloned voice is used as a substitute. Until real clips are added, these slots stay silent.
