# Diaper Boy Milei · Hikari Studios
A mobile, App Store inspired parody listing for the existing Diaper Run game. The Obtener and demo buttons open the real game fullscreen in a browser dialog. The page uses five supplied portrait promos in the requested order, followed by a compressed gameplay loop after promo three, plus the bundled game runtime.

Static site; no build step or external dependencies. Open Graph and Twitter metadata point to the 1200×630 share card at the public absolute URL. The visible “Compartí con tus amigos” action opens the native share sheet or copies the link. All links are relative so it works at the GitHub Pages repository path. Rename the game by changing `GAME_NAME` once in `app.js`.

Ratings, rankings, reviews, “offline” copy, and the version note are fictional parody. The gallery captions identify the promo order; the inserted loop is compressed silent H.264 video and pauses off-screen, with reduced-motion and data-saver support. The footer identifies Hikari Studios and states the political parody/non-affiliation.
